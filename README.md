# 🏢 ERP Warehouse Pro (منظومة إدارة المخازن والمستودعات والبضائع المتكاملة)

منظومة **ERP** مؤسسية متكاملة مصممة لإدارة المستودعات، المخزون، البضائع، حركات الإدخال والصرف، نقاط البيع والمبيعات (POS)، مع دعم كامل للباركود وقواعد البيانات السريعة.

---

## 🚀 التك ستاك المعتمد (Tech Stack)

| الطبقة (Layer) | التقنية المستخدمة | الوصف والوظيفة |
| :--- | :--- | :--- |
| **الباك إند (Backend)** | **C# (.NET Core 8 Web API)** | معمارية Clean Architecture عالية الأداء والأمان لإدارة العمليات المالية واللوجستية. |
| **لوحة التحكم (Web Dashboard)** | **Next.js (React + TypeScript)** | لوحة تفاعلية حديثة فائقة السرعة مع دعم كامل للغتين (العربية RTL / الإنجليزية LTR) والسمات (Dark/Light). |
| **تطبيقات الموبايل والحاسبة (Cross-Platform)** | **Flutter (Dart)** | كود موحد يدعم Android, iOS, Windows, macOS مع قارئ باركود بالكاميرا وإدارة الجرد. |
| **قاعدة البيانات (Database)** | **PostgreSQL 16** | جداول علائقية متقدمة، قيود سلامة البيانات، وفهارس بحث بالباركود وSKU. |
| **التخزين المؤقت والسرعة (Cache)** | **Redis 7** | كاش فائق السرعة لقراءة الباركود والأسعار في أجزاء من الملي ثانية. |
| **الحاويات والتشغيل (DevOps)** | **Docker & Docker Compose** | بيئة تشغيل متكاملة جاهزة للإنتاج بضغطة زر واحدة. |

## 🌟 الميزات والوحدات الرئيسية (Core Modules)

1. **📊 لوحة العمليات اللوجستية (Logistics Overview):**
   - مؤشرات الأداء اللوجستية: القيمة الإجمالية للمخزون بسعر التكلفة ($).
   - مخطط التدفق اللوجستي الشهري (الوارد IN مقابل المنصرف OUT).
   - نسب إشغال المستودعات بالسعة الحجمية ($m^3$).
   - تنبيهات نقص المخزون الحرجة (Reorder Thresholds).

2. **📦 دليل البضائع والمخزون (Inventory & Catalog):**
   - تتبع البضائع بالباركود الدولي ورمز SKU الفريد.
   - مراقبة هوامش الربح لكل صنف (سعر التكلفة مقابل سعر البيع).
   - تتبع أماكن التخزين بدقة الرف والقاطع (Shelf Location).

3. **🔄 حركات المخزون والمناقلات (Stock Movements):**
   - أذونات استلام وتوريد (IN).
   - أذونات صرف ومبيعات (OUT).
   - مناقلات فورية بين المستودعات والفروع (Transfer).
   - تسويات جردية وفروقات التالف (Adjustment).

4. **🛒 فواتير المبيعات ونقاط البيع (Sales & POS):**
   - نقطة بيع سريعة مع سلة مشتريات حية.
   - احتساب فوري للمجموع، ضريبة القيمة المضافة، والخصومات.
   - طرق دفع متعددة: نقدي (Cash)، بطاقة بنكية (Card)، أو آجل (Credit).
   - خفض فوري وتلقائي لرصيد المستودع عند تأكيد البيع.

5. **📷 قارئ الباركود التفاعلي (Interactive Barcode Scanner):**
   - محاكي قارئ الليزر للبحث الفوري عن الأصناف.
   - أزرار سريعة لتعديل كميات المخزن (+ / -).

## 🛠️ خطوات التشغيل المحلي (How to Run)

### 1. تشغيل لوحة تحكم الويب (Web Dashboard):
```bash
cd web-dashboard
npm install
npm run dev
```
تفتح الواجهة مباشرة على الرابط: `http://localhost:5173/`

### 2. تشغيل النظام بالكامل عبر Docker Compose:
```bash
docker-compose up -d
```
يقوم بتشغيل:
- PostgreSQL على المنفذ `5432`
- Redis على المنفذ `6379`
- .NET API على المنفذ `5000`
- لوحة الويب على المنفذ `3000`
